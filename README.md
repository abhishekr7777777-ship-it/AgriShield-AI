# AgriShield AI

An AI-powered smart agriculture platform designed to help Indian farmers make informed farming decisions.

## Problem Statement

Farmers face challenges such as unpredictable weather, crop diseases, nutrient deficiencies and limited access to agricultural guidance.

## Our Solution

AgriShield AI combines artificial intelligence, real-time weather information and agricultural calculators into a single user-friendly dashboard.

## Key Features

- **AI Crop Doctor:** Image-based crop disease assessment and treatment guidance.
- **AI Farming Assistant:** Agricultural guidance in English, Kannada and Hindi.
- **Live Weather:** Real-time weather information and five-day forecasts.
- **Weather Risk Assessment:** Rain and heat risk screening.
- **Soil Health Analysis:** AI-assisted interpretation of NPK readings.
- **Smart Farm Calculator:** Irrigation, seed and fertilizer requirement calculations.

## Technologies Used

- HTML, CSS and JavaScript
- Node.js
- Express.js
- Google Gemini API
- Open-Meteo API

## How to Run

1. Download or clone this repository.
2. Run `npm install`.
3. Create a `.env` file containing `GEMINI_API_KEY=your_api_key`.
4. Run `node server.js`.
5. Open http://localhost:3000 in your browser.
